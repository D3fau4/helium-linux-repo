Helium APT Repository

Install Helium and keep it up to date with apt, instead of downloading the .deb by hand on every release.

Install

Copy the whole block and paste it into a terminal:

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://helium.repo.not-d3fau4.com/helium-linux.gpg -o /etc/apt/keyrings/helium-linux.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/helium-linux.gpg] https://helium.repo.not-d3fau4.com stable main" \
  | sudo tee /etc/apt/sources.list.d/helium-linux.list
sudo apt update
sudo apt install helium-bin

deb822 alternative

For the modern format (Debian 12+, Ubuntu 24.04+, Linux Mint 22+):

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://helium.repo.not-d3fau4.com/helium-linux.gpg -o /etc/apt/keyrings/helium-linux.gpg
sudo tee /etc/apt/sources.list.d/helium-linux.sources >/dev/null <<EOF
Types: deb
URIs: https://helium.repo.not-d3fau4.com
Suites: stable
Components: main
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/helium-linux.gpg
EOF
sudo apt update && sudo apt install helium-bin

Update

Nothing special from here on: Helium updates along with the rest of the system.

sudo apt update && sudo apt upgrade

Uninstall

sudo apt remove helium-bin
sudo rm -f /etc/apt/sources.list.d/helium-linux.list \
           /etc/apt/sources.list.d/helium-linux.sources \
           /etc/apt/keyrings/helium-linux.gpg
sudo apt update

How it works

Helium's .deb packages are around 130 MB, so this site does not host them. It publishes only the signed APT metadata (Packages, Release, InRelease) and redirects the pool paths to the original assets on GitHub Releases.

What you install is exactly what the project ships: apt checks each package's SHA256 against the one in the signed metadata, so the redirect does not weaken verification.
